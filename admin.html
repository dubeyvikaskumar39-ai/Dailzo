Steps to make this a real admin system

  1. Set up a hosted database with a free-tier plan, after checking current limits.
  2. Enable real authentication; never store an admin password in HTML or JavaScript.
  3. Set database access rules so only authorized staff can manage products and orders.
  4. Connect the customer shop, cart, checkout, inventory and this panel to the same database.
  5. Test on two devices before accepting real orders.
